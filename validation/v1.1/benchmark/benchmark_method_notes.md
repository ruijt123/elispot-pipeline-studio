# Benchmark method notes

- Benchmark scope: 10 panels from 7 papers; the same set guided code refinement, so this is a development benchmark.
- Structure is inferred deterministically from border, internal-lattice, and color/edge periodicity evidence.
- Numeric extraction is allowed only when printed glyph evidence is present.
- Dense printed panels use indexed-row and fixed-shape readings. Disagreement triggers a local chunk reread with tool-assigned coordinates.
- Accuracy is reported separately for the initial indexed pass, automatic routing before rereading, and the final development cascade.
- Sparse and nested panels use indexed row or block atlases.
- Color-only panels abstain; numeric values are never inferred from color.
- Qwen sampling parameters: temperature=0, top_p=0.01. high/medium/low remains model_self_reported_confidence. uses_numeric_confidence_threshold=False.
- Manual ground truth was transcribed from source figures. No ground truth was generated by the model.
